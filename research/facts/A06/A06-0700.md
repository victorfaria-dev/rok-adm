# Season in which each commander becomes available, per the rkg tier list (Season 0 / 2 / 3) — table

The riseofkingdomsguides.com tier list (headed "October 2026") gives a "Season" column in 101 rows (100 commanders; Gonzalo de Córdoba appears twice, both "Season 3"): 36 are "Season 0" (available before KvK1), 8 are "Season 2" and 57 are "Season 3". The list has no "Season 1" and no separate Season of Conquest label, so "Season 3" reads as "Season 3 or later". The full table is in `data/rkg-commander-season.csv`.
