# Base healing cost per unit by tier (riseofkingdomsguides calculator): T4 120/120 + 8 gold; T5 320/320 + 160 gold

The riseofkingdomsguides healing calculator uses these base healing costs per unit (before healing-cost reductions): T4 infantry 120 food + 120 wood + 8 gold, T5 infantry 320 food + 320 wood + 160 gold (archers use wood+stone, cavalry food+stone, same totals). T5 gold per heal is 20× T4 and food/wood about 2.7×; base heal time per unit 3 s (T4) vs 4 s (T5).
