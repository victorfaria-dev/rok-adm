# Referências de design

Sites para inspirar o design do megahub, agrupados pelo módulo que inspiram. A lista é de conhecimento prévio do admin e ainda não foi revisitada; vale abrir cada site e anotar prints do que copiar.

## Guias e builds (Guide Engine, Guide Builder)
| Site | O que observar |
|------|----------------|
| maxroll.gg | Padrão-ouro de guia de jogo: guias por etapa, planners de build, avisos de "atualizado no patch X" |
| mobalytics.gg | Guias com filtros por estilo de jogo, tier lists, perfil do jogador com métricas |
| prydwen.gg | Tier lists e fichas de personagem limpas (gacha → análogo a comandantes) |
| wowhead.com | Base de dados enorme com tooltips, comentários e guias ligados aos dados |

## O que evitar (concorrência de RoK)
Os sites de guia de RoK mapeados em `research/context/competitors-and-constraints.md` sofrem de excesso de anúncios, SEO spam, datas de atualização falsas e UX ruim no celular. Contraste deliberado: rápido, mobile-first, sem poluição, com patch e data em cada informação.

## Princípios que saem dessas referências
1. **Mobile-first:** RoK é jogado no celular, então o hub é consultado com o jogo aberto.
2. **"Verified on patch X"** visível em cada dado.
3. **Recomendação explicada:** sempre o "por quê" junto do "o quê".
4. **Identidade visual forte:** perfis e alianças com cor, brasão e cartões compartilháveis.
5. **Densidade com clareza:** tabelas e calculadoras ricas, mas legíveis.
