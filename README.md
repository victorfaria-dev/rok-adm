# rok-adm

Pesquisa, guias e (futuramente) sistema de gestão/planejamento para **Rise of Kingdoms**: gestão de conta com máximo aproveitamento de tempo e administração de reino.

## Estrutura

```
research/
  00-PLANO.md        plano de pesquisa: objetivos, premissas, fases, riscos
  taxonomia.md       domínios do jogo usados para classificar fatos
  fontes.md          registro de fontes e níveis de confiança
  agentes.md         contratos dos subagentes (coleta, organização, verificação, contexto)
  schemas/           formatos das fichas de fato, de dor e dos pacotes de contexto
  raw/               notas brutas dos coletores
  facts/             fichas de fato normalizadas e verificadas
  pains/             fichas de dores dos jogadores
  context/           pacotes de contexto para escrever guias/sistema
```

Comece por [`research/00-PLANO.md`](research/00-PLANO.md).
